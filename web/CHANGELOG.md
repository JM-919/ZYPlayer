# 更新记录（网页版）

## 2026-10-07(晚) · 首页改豆瓣榜单 + 照博客做自适应

* **首页/刷新改用豆瓣榜单**（正在热映/热门电影/热门剧集/综艺/动漫）：首页不再依赖采集源；
  榜单项点进去自动按片名聚合搜索再进详情（`pendingOpenName`）。
* **去掉右上角 `vdev` 那行小字**（构建角标）：仍然会在后台比对 `/version.json`，但**安静**——
  没在看片时自动换新版，看片中只在控制台记一句。
* **默认开关**（网页端）：静默提示 **开**、画面上显示 **关**、避开烧录广告源 **关**。
* **自适应照静态博客重做**：文档自然滚动（不再是"整屏 App 壳"）、容器限宽 1080px、
  流式网格 `repeat(auto-fill,minmax(...))`、断点 560/720/880/1180 —— 与博客 felixdsh2.eu.cc 同一套思路。

## 2026-10-07 · 只做点播：直播整体摘除 + 撤回新皮肤

* **直播功能整体移除**（网页版）：顶栏「直播」入口、直播页、频道表、与直播有关的设置行
  （跨分组换台/频道倒序/清空线路记忆）全部下线；桥里的直播代码（频道表抓取/解析/合并/探活/PK.live*）
  整段删除，共删约 6.3 KB。**本版只做点播**（搜索 / 详情 / 换源 / 播放 / 广告过滤）。
* **撤回新皮肤**：上一版那层 Aurora Glass（悬浮顶栏岛/极光配色/大圆角卡片等 6.5 KB 样式）整段删除，
  回到做新皮肤之前的样式；**只保留桌面响应式布局**（宽屏居中、卡片多列）。
* **撤回把点播改坏的改动**：Worker 不再改写清单（它会把分片拖到海外出口 → 国内 CDN 403），
  取流路径回到「Service Worker 在用户本机直连」；删掉 live 专用的 Worker 出口与"坏源记忆"。
* **起播途中不再提前报错**：hls.js 起播时常见的"先 404/超时、随后成功"不再弹提示，
  只在真的没有备用源、播不动时才把原因留在屏幕上。
* **文档分开保存**：网页版文档只在 `web/`（本目录），安卓端文档在工程根目录，两套互不混写。


## 1.0.0-web — 首个正式网页版

* **从安卓工程里独立出来**：仓库只放网页版，界面源码在 `web/site/`（`build-web.mjs` 会与本地安卓工程自动同步）。
* **站点与代理同域**：静态资源内置进 Cloudflare Worker，`/f` `/p` 提供代理，不需要 DNS 权限；
  另有独立代理域名 `zyapi.hof12.ccwu.cc` 作备用入口。
* **修掉「电脑上没声音」**：播放前摘掉浏览器自动播放策略留下的 `muted`，被策略挡下时给出
  「点一下开始播放」的明确入口；设置里加了音量条 / 静音按钮，PC 上可用 `↑↓`、滚轮调音量。
* **修掉「横屏竖屏不能用」**：先全屏再锁方向（浏览器规定如此），桌面端锁不了就不显示该按钮。
* **移除网页版做不了的安卓专属功能**（按钮 + 入口 + 抽屉一起清掉）：投屏(DLNA)、解析线路、
  蜘蛛源(jar)、调起外部播放器、应用内更新、播放本地文件；App 侧行为不变。
* **播放器在电脑上好用起来**：全屏按钮、键盘快捷键（空格/←→/↑↓/F/M/Shift+滚轮）、滚轮调音量、
  自动隐藏面板时鼠标移入即出。
* 页面标题 `PikachuTV` → **ZY影视**。
* 代理侧两个坑写进注释与文档：目标地址改用 base64url 的 `q` 参数；**必须带 User-Agent**
  （否则采集站 WAF 回 `403 Forbidden By WAF` 被原样透传，看起来像代理被墙）。
